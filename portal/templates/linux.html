Options et cas particuliers
  • Cache seul, sans les dépôts loco : ajoutez --cache-only ; garder l'ancien dépôt unique : --legacy.
    • {% if http_url %}
  • Poste qui n'a pas encore l'autorité loco : curl -fsSL {{ http_url }}/linux/setup.sh | sudo sh -s -- --trust-ca (importe l'autorité, puis passe en HTTPS).
    • {% endif %}
  • Sans curl : remplacez curl -fsSL par wget -qO-.
  • Les dépôts HTTPS des éditeurs restent en accès direct ; les dépôts HTTP passent par le cache. Clé de signature : loco.gpg.
