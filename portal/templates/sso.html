Ajouter un fournisseur

Remplacez les exemples TENANT, REALM, APPLICATION… par vos valeurs. Pour Entra ID, utilisez l'UUID du tenant précis. Copiez l'émetteur exact, avec sa barre finale si le fournisseur l'impose. GitHub utilise OAuth 2 ; les autres modèles utilisent OpenID Connect.

L'URL de retour apparaît après l'ajout. Déclarez une application web avec le flux code d'autorisation et PKCE S256. Le serveur doit pouvoir joindre les URL HTTPS du fournisseur. Pour un annuaire privé, son autorité doit être reconnue par le système du serveur loco.
