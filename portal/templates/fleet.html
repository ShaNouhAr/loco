Ajouter un poste

Windows 10/11 et Windows Server 2016 et plus, dans PowerShell administrateur.

{{ cmd('agent-win', commands.windows, 'PS>') }} {% if commands.windows_http %}Autorité loco pas encore importée sur le poste : {{ commands.windows_http }}{% endif %} Installe le service Windows loco-client (MSI, visible dans Programmes et fonctionnalités). L'agent épingle l'autorité de loco sans modifier les certificats du poste.
Déploiement en masse (GPO, Intune, SCCM)

Distribuer loco-client.msi{% if msi_error %} ({{ msi_error }}){% endif %} et créer, par GPO (préférences de registre), sous HKLM\SOFTWARE\Policies\loco\Client les valeurs chaîne :

Server = {{ https_url }}
Key = {{ enroll_key }}
CaSha256 = {{ ca_sha256 or '(vide : certificat public)' }}

Ou en ligne de commande : msiexec /i loco-client.msi SERVER={{ https_url }} KEY={{ enroll_key }} CA_SHA256={{ ca_sha256 }} /qn

Postes avec systemd et APT ou DNF.
